Notes

Usage / Security
  1. 可上傳 Clash/Mihomo YAML；不選檔案時會使用內建預設 YAML。
  2. 輸入 vmess/vless 節點後，系統會替換原 proxies 節點。
  3. rules、rule-providers、dns、proxy-groups 等設定會盡量保留。
  4. 系統會自動新增國旗、國家策略組、通用策略組。
  5. 勾選 Policy Options 後，新節點會加入對應特殊策略組。
  6. 生成完成後會自動跳到 Generate Result，並提供線上下載連結。
  7. 輸出檔名格式為 tim_日期_當日序號_隨機標識.yaml。

LOG SAFE / 不記錄完整節點連結、UUID 或密碼。

UPDATE SAFE / 一鍵升級會保留 .env、預設 YAML、輸出與備份。

ACCESS / 建議透過 HTTPS、Tailscale、WireGuard 或內網存取。
