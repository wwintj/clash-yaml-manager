Usage / Security
  1. Upload Clash/Mihomo YAML or use the built-in default when no file is selected.

  5. Select Policy Options to add new nodes to the corresponding special groups.
  6. After generation, Generate Result shows the download link.
  7. Output filenames follow tim_date_daily-sequence_random-id.yaml.

Updates preserve .env, default YAML, outputs and backups.
